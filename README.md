# HotelMe PMS — Desktop

Installers for the HotelMe PMS desktop app. This repository holds releases only.

**Download for Windows:** [HotelMe-PMS-Setup.exe](https://github.com/muhammedaslan34/hotelme-pms-desktop-releases/releases/latest/download/HotelMe-PMS-Setup.exe)

The app updates itself from the latest release.

Windows may show a SmartScreen warning because the installer is not signed yet: choose **More info → Run anyway**.
